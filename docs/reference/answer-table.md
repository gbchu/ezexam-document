# `answer-table` 方法 <Badge type="warning" text="0.4.0" />

该方法为可方便的将答案以表格形式显示


#### 示例
```typst
#answer-table[A][B][C][D]
```
效果：

| 题号 | 1 | 2 | 3 | 4 |
| ---- | ---- | ---- | ---- | ---- |
| 答案 | A | B | C | D |


### 参数

#### `rows`

`类型: int`

`默认值: 2`

>该参数用于设置表格行数

#### `cell-x`

`类型: length`

`默认值: 1.25em`

>该参数用于设置单元格左右内间距

#### `cell-y`

`类型: length`

`默认值: 0.5em`

>该参数用于设置单元格上下内间距

#### `answers`

`类型: content | str`

`默认值: 无`

>该参数为位置参数，要显示的答案
